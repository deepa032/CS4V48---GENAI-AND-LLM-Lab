## 📖 Overview

This repository contains the laboratory experiments completed for the **CS4V48 – Generative AI and Large Language Models** course.

The experiments demonstrate practical applications of modern **Foundation Models** and **Large Language Models (LLMs)** using **Google Colab**, **Hugging Face Transformers**, **Diffusers**, **FAISS**, **Gradio**, and **PyTorch**.

The repository covers text generation, prompt engineering, conversational AI, summarization, question answering, sentiment analysis, retrieval-augmented generation (RAG), AI-assisted code generation, image generation, multimodal AI, model fine-tuning, multimedia generation, and deployment of AI applications.

---

## 🎯 Objectives

- Understand Foundation Models and Large Language Models.
- Perform inference using pre-trained transformer models.
- Apply prompt engineering techniques.
- Build conversational AI systems.
- Generate summaries and answer questions.
- Perform sentiment analysis.
- Implement Retrieval-Augmented Generation (RAG).
- Generate and debug source code using AI.
- Generate images from text prompts.
- Perform multimodal AI tasks.
- Fine-tune transformer models.
- Deploy Generative AI applications using Gradio.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/deepa032/CS4V48---GENAI-AND-LLM-Lab.git
```

Move into the project directory:

```bash
cd CS4V48---GENAI-AND-LLM-Lab
```

Install the required packages:

```bash
pip install transformers
pip install diffusers
pip install datasets
pip install accelerate
pip install sentencepiece
pip install gradio
pip install faiss-cpu
pip install torch
```

Or install everything at once:

```bash
pip install transformers diffusers datasets accelerate sentencepiece gradio faiss-cpu torch
```

---

# 🚀 Running the Experiments

1. Open the notebook in **Google Colab**.
2. Enable **T4 GPU**:
   - Runtime → Change runtime type
   - Hardware Accelerator → **T4 GPU**
3. Run all cells sequentially.
4. For experiments requiring authentication, add your **Hugging Face Access Token** using Colab Secrets.
